# Narrative Arcs & Beat Mapping Guide

Select a narrative arc that fits the topic and duration:

## Narrative Arcs (`arc`)

1. **`timeline`** (Historical / Evolution):
    - Beat 1: Origin / The Before State (Hook: surprising stat or paradox)
    - Beat 2: The Breakthrough / Spark
    - Beat 3: Rapid Expansion / Turning Point
    - Beat 4: Modern Reality / Consequence / Payoff

2. **`pas` (Problem - Agitate - Solution)** — Best for Ads & Tech:
    - Beat 1: The Frustrating Status Quo (Hook: relatable pain point)
    - Beat 2: The Escalation / Hidden Friction
    - Beat 3: The New Paradigm / Solution Reveal
    - Beat 4: Transformation / Call to Action

3. **`how_it_works`** (Educational / Explainer):
    - Beat 1: The Big Question (Hook: counter-intuitive fact)
    - Beat 2: Core Mechanism / Engine Step 1
    - Beat 3: Hidden Mechanics / Engine Step 2
    - Beat 4: Summary / Future Outlook

4. **`man_in_hole`** (Transformation / Rise & Fall):
    - Beat 1: Peak Comfort or Normal World
    - Beat 2: The Sudden Drop / Crisis
    - Beat 3: The Reconstruction / Rebirth
    - Beat 4: Higher Ground / Payoff

## Shot Cadence Rules

- Split each 8–10s beat into **2 shots** (Shot `a` wide + Shot `b` detail cut-in).
- Shot `a` duration: 3–5 seconds. Headline text baked in.
- Shot `b` duration: 3–5 seconds. Close-up cut-in, no headline text.
