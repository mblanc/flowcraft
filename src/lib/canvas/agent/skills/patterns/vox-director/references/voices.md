# Voice Selection Matrix for Narration (t2s)

Match narrator voice direction to topic tone:

- **Documentary / Explainer**: Warm, authoritative, deliberate pace. "Narrator voice, clear articulation, documentary tone, moderate pace."
- **Tech / Modern Ad**: Energetic, confident, crisp. "Modern tech founder voice, upbeat pacing, articulate."
- **Historical / Story**: Deep, resonant, slow. "Classic storyteller voice, deep resonance, thoughtful pacing."
- **Default TTS Model**: `gemini-3.1-flash-tts-preview`
